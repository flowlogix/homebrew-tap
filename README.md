# Flow Logix Homebrew Tap

Homebrew formulas for Flow Logix tools.

## JStarter

JStarter, the Jakarta EE Starter by Flow Logix, creates a complete, testable Jakarta EE project.

```bash
brew install flowlogix/tap/jstarter
```

Formulas here are published automatically by each release, from [flowlogix/apps](https://github.com/flowlogix/apps). Please report problems there.
